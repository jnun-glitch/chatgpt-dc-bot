Dashboard

Dies ist die lokal gehostete Dashboard-Oberfläche für deinen Discord-Bot. Alle Daten werden nur lokal geladen und sind nur von diesem PC aus erreichbar.

Gehe auf einen Bereich in der Navigation, um Informationen zu Servern, Channels, Commands oder Nachrichten zu sehen.

Schnellzugriff

  • Server Übersicht aller Server, die dein Bot betreut.
  • Messages Live-Nachrichten-Vorschau und Senden von Nachrichten.
  • Executor Liste verfügbarer Commands und Ausführungshilfe.
  • Config Server-spezifische Einstellungen ändern.
